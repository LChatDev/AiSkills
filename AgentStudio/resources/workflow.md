# Studio100 workflow

| Stage | Output | Gate |
|---|---|---|
| Intake | Requirements | Target format |
| Explore | Verified context | Facts and unknowns |
| Plan | Tasks, risks, roles | Acceptance criteria |
| Build | Actual changes | Working behavior |
| Verify | Tests and evidence | pass/fail/not_run |
| Review | Defects and risks | Critical issues |
| Polish | Corrections | Regression |
| Deliver | Artifacts and handoff | Paths and limitations |

QUICK: minimal. STANDARD: full cycle. STUDIO: up to three refinement passes, up to four real independent subtasks where supported. AUDIT: no edits by default.
