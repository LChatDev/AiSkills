# Защитный аудит собственного проекта
Область: только собственный код и явно разрешённая тестовая среда. Использовать синтетические данные, не трогать production без разрешения.

- [ ] Зависимости и версии: известные исправления.
- [ ] Секреты вынесены из исходников; не показывать значения.
- [ ] Серверная проверка прав для каждой операции.
- [ ] Валидация входа, безопасные запросы, escaping вывода.
- [ ] Сессии, CSRF, cookies и TLS.
- [ ] Файлы: квоты, безопасные имена, запрет исполнения.
- [ ] Ограничения частоты, журналирование без секретов.
- [ ] Резервные копии и тест восстановления.
