# Контроль графики
- [ ] Назначение, стиль и композиция соответствуют задаче.
- [ ] Чёткий силуэт, логичная перспектива, свет и материалы.
- [ ] Нет лишних деталей, деформаций и артефактов.
- [ ] Надписи точны; читаемость в целевом размере проверена.
- [ ] Для pixel art — чёткая сетка; тайлы проверены на стыках.
- [ ] Для иконки — безопасные поля и малый размер.
- [ ] Для редактирования — сохранены неизменяемые области.
- [ ] Реальные формат, размеры, прозрачность и слои проверены.
- [ ] Права на использованные ресурсы учтены.

Не обещать SVG, PSD или анимацию, если создан только растр.
