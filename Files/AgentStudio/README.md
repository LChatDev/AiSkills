# AgentStudio (Studio100)

Переносимый навык с шестью адаптерами. Скопируй папку AgentStudio целиком и назови agentstudio. В чатах без поддержки Skills приложи SKILL.md и нужные ресурсы.

| Платформа | Способ | Профиль |
|---|---|---|
| Claude / Claude Code | .claude/skills/agentstudio/ | [claude.md](platforms/claude.md) |
| ChatGPT | Skills в поддерживаемом интерфейсе | [chatgpt.md](platforms/chatgpt.md) |
| Grok / Grok Build | .grok/skills/agentstudio/ | [grok.md](platforms/grok.md) |
| Cursor | .cursor/skills/agentstudio/ | [cursor.md](platforms/cursor.md) |
| VS Code / GitHub Copilot | .github/skills/agentstudio/ | [vscode.md](platforms/vscode.md) |
| Gemini / Gemini CLI | .gemini/skills/agentstudio/ | [gemini.md](platforms/gemini.md) |
