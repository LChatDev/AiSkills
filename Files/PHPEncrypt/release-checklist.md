# Выпуск защищённой копии собственного PHP-кода
Шаблон конфигурации описывает требования; это не исполняемый обфускатор.
- [ ] Есть право преобразования исходников и резервная копия.
- [ ] Преобразования выполняются только в отдельном dist.
- [ ] Токенизация/парсер, сохранены лицензии, публичные API и динамические ссылки.
- [ ] Нет eval, скрытого исполнения и упаковки исполняемых строк.
- [ ] Нет секретов в выходном архиве.
- [ ] php -l каждого файла и тесты до/после.
- [ ] Совместимость с целевым PHP и хостингом проверена.
- [ ] Документирован откат.

Минификация и консервативная обфускация не являются шифрованием и не гарантируют нераскрываемость кода.
