# Частное файловое хранилище
Пример (создавать вне document root):

    private-data/
      users/<random-id>.json
      chats/<random-id>/messages-000001.jsonl
      files/<random-id>.bin
      index/
      locks/
      journal/

Все пути формируются сервером из валидированных ID; не из email или произвольного пути. Не хранить открытые пароли. Блокировки на отдельном стабильном файле, проверка версии и прав, временный файл в том же каталоге, атомарная замена там, где она гарантирована. Проверять размер и результат записи. Операции на нескольких файлах требуют журнала и восстановления.

## Проверки
- [ ] Параллельное обновление.
- [ ] Повреждённый JSON / прерванная запись / полный диск.
- [ ] Изоляция аккаунтов и запрет прямого HTTP-доступа.
- [ ] Квоты, удаление, резервное копирование, восстановление.
