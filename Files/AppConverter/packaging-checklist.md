# PWA, Android, desktop
Manifest — шаблон: заменить название, scope и пути; создать реальные иконки.
- [ ] HTTPS и корректный manifest.
- [ ] Установка, запуск, навигация, back и внешние ссылки.
- [ ] Офлайн-экран и обновление; не кешировать приватные ответы.
- [ ] Минимальные разрешения; доверенные origin и TLS.
- [ ] Android: package ID, версии SDK, debug/release подпись.
- [ ] Desktop: целевая ОС/архитектура, безопасная оболочка.
- [ ] Фактический APK/EXE/installer собран и проверен.
- [ ] Изменения и непроверенные платформы перечислены.

Не считать manifest готовым приложением; SDK и реальные ресурсы нужны отдельно.
