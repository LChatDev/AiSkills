# AiSkills

Коллекция готовых скиллов для ИИ-агентов: разработка программного обеспечения и профессиональный UI/UX.

## Скиллы

| Скилл | Назначение | Файл |
| --- | --- | --- |
| AutoDev | Разработка, исправление ошибок, тестирование, сборка EXE, APK, JAR, ZIP | [SKILL.md](AutoDev/SKILL.md) |
| Interface | Дизайн GUI, адаптивность, дизайн-системы, брендинг, визуальная проверка | [SKILL.md](Interface/SKILL.md) |

## AutoDev — промпт для подключения

Скопируй следующий промпт в своего ИИ-агента:

```text
Скачай скилл AutoDev из официального репозитория AiSkills:

https://raw.githubusercontent.com/LChatDev/AiSkills/main/AutoDev/SKILL.md

Прочитай SKILL.md полностью. Если твоя среда поддерживает Agent Skills, установи файл как autodev/SKILL.md в соответствующую папку скиллов. Если нет — используй его как инструкции для текущей задачи.

Активируй AutoDev. Применяй его при создании проектов, добавлении функций, исправлении ошибок, тестировании и сборке программ. Самостоятельно выбирай подходящий режим, используй доступные инструменты и проверяй результат. Не ограничивайся примерами кода, если можешь создать рабочий проект. Не утверждай, что сборка или тесты выполнены, если они не запускались.

После подключения сообщи, что скилл прочитан и готов к применению. Если скачать или установить его невозможно, укажи причину.
```

## Совместное использование

При разработке приложений с GUI можно подключить оба скилла: AutoDev отвечает за программирование, сборку и тестирование, Interface — за дизайн и пользовательский интерфейс.

## Установка вручную

```bash
git clone https://github.com/LChatDev/AiSkills.git
```

Размести нужные файлы SKILL.md в каталогах скиллов своего агента. Если агент требует совпадения имени папки с полем name в метаданных, используй имена autodev и interface.

Скиллы являются текстовыми инструкциями для ИИ, а не исполняемыми плагинами. Доступные возможности зависят от инструментов конкретного агента.
