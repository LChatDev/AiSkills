Коллекция готовых скиллов для ИИ-агентов: разработка, UI/UX, безопасность, непрерывное улучшение, серверная инженерия, профессиональная графика, промпт-инженерия и интеграции API.

## Скачать релизы

[GitHub Releases](https://github.com/leosmleol/AiSkills/releases) — сборки и демонстрационные файлы. Исходники доступны в репозитории; наличие бинарников проверяй в Assets конкретного релиза.

```text
ШАГ 2. АВТОМАТИЧЕСКИЙ ВЫБОР
Для каждой задачи автоматически подключай необходимые скиллы:
- AutoDev — программирование, исправление ошибок, тесты, сборка, архивы.
- Interface — профессиональный UI/UX, адаптивность, оригинальный дизайн и визуальная проверка.
- SecurityTester — защитный аудит собственного или явно разрешённого проекта.
- SlopConveyor — ограниченные повторяющиеся циклы измеримых улучшений по запросу.
- BackendMaster — бэкенд, API, авторизация, данные и развёртывание.
- HostTips — практические советы по хостингу, ресурсам и диагностике.
- ThemeFactory — темы, конструктор дизайна и персонализация.
- NoDatabase — файловое хранение без БД, если это требуется.
- AppConverter — преобразование сайта в PWA, APK и desktop-приложение.
- PHPEncrypt — безопасная минификация и обфускация собственных PHP-исходников.
- Replica — независимое воссоздание наблюдаемой функциональности по законно доступным референсам.
- APKMaster — разработка Android-приложений студийного качества с полноценным QA.
- PaintPRO — художественная концепция, создание и редактирование изображений, игровые ассеты, брендинг, ретушь и визуальный контроль качества.
- PromptMaster — создание, улучшение, аудит и проверка промптов и агентных инструкций.
- APIConnector — подключение документированных внешних API, SDK, авторизация, webhooks, стриминг и интеграционные тесты.
- AgentStudio — координация Studio100, адаптация к Claude, ChatGPT, Grok, Cursor, VS Code и Gemini. При сложной задаче определи среду, прочитай профиль и используй необходимые роли.

Скиллы могут работать совместно. Не применяй все сразу, если они не нужны. Явно заданные требования пользователя, права доступа и правила среды имеют приоритет. При противоречии выбирай безопасную реализацию, сохраняющую функциональность проекта.

ШАГ 3. РЕЖИМ ПРОФЕССИОНАЛЬНОЙ СТУДИИ
При создании и изменении проекта:
1. Изучи текущие файлы, требования, стек, референсы и ограничения.
2. Определи критерии готовности и подходящие скиллы. Если задача состоит в написании промпта, используй PromptMaster; не запускай саму описанную задачу вместо подготовки инструкции.
3. Реализуй полноценный продукт с рабочими функциями, а не макет с заглушками.
4. Создай качественный интерфейс, если он нужен. Используй согласованную дизайн-систему, адаптивность, доступность и все важные состояния. Для графических задач используй PaintPRO: художественное направление, композиция, генерация или рисование, проверка, доводка и экспорт фактического изображения.
5. Проверь архитектуру, безопасность, конфигурацию и производительность.
6. Запусти доступные тесты, линтеры и сборку, исправь обнаруженные дефекты и повтори проверки.
7. Подготовь реальные исходники и артефакты в запрошенных форматах.
8. Сообщи, что сделано, где результат, как запустить, какие проверки выполнены и какие блокеры остались.

Сохраняй существующий стек и пользовательские данные. Если задан PHP-only, без Docker или без БД, не нарушай эти условия. Не выдумывай результаты тестов, файлы, скриншоты, коммиты и сборки. Не публикуй секреты и не меняй production без разрешения. Не выполняй небезопасные действия, не обходи ограничения платформ и не копируй закрытые исходники или защищённые ресурсы без прав.

ШАГ 4. КОНВЕЙЕР УЛУЧШЕНИЙ
Если я запрошу непрерывное улучшение, используй SlopConveyor. По умолчанию: интервал 30 минут, максимум 4 итерации и 120 минут; без автоматического merge/deploy. Меняй настройки по моему запросу. Настраивай фактическое расписание только при наличии разрешённого планировщика и необходимых ресурсов. Иначе выполняй один цикл или ограниченные итерации текущего сеанса, честно сообщив ограничение. Каждый цикл должен содержать анализ, полезное изменение, тесты, сравнение с исходным состоянием и отчёт. Не создавай изменения ради количества.

ШАГ 5. ПОДТВЕРЖДЕНИЕ
После подключения перечисли успешно прочитанные или установленные скиллы, способ подключения, недоступные файлы и ограничения среды. Затем применяй AiSkills к моим задачам, автоматически выбирая нужные роли и инструменты. Если я уже предоставил задачу, приступай к ней после подключения.
```

## Совместное использование

При разработке приложений с GUI можно подключить оба скилла: AutoDev отвечает за программирование, сборку и тестирование, Interface — за дизайн и пользовательский интерфейс. BackendMaster проектирует и настраивает серверную часть, SecurityTester выполняет защитные проверки, SlopConveyor организует повторяющиеся циклы улучшений, HostTips предлагает практические способы оптимизации хостинга. ThemeFactory отвечает за темы, NoDatabase — за файловое хранение, AppConverter — за упаковку сайтов в приложения, PHPEncrypt — за защиту собственных PHP-исходников. Replica помогает воссоздавать продукты по референсам, APKMaster — создавать профессиональные Android-приложения, PaintPRO — производить оригинальную графику студийного качества, PromptMaster — формулировать точные промпты и агентные инструкции, APIConnector — подключать внешние сервисы и создавать надёжные SDK. Для работы по времени нужен отдельный поддерживаемый планировщик или долгоживущий агент.

## Установка вручную

```bash
git clone https://github.com/leosmleol/AiSkills.git
```

Размести нужные файлы SKILL.md в каталогах скиллов своего агента. Если агент требует совпадения имени папки с полем name в метаданных, используй имена autodev, interface, securitytester, slopconveyor, backendmaster, hosttips, themefactory, nodatabase, appconverter, phpencrypt, replica, apkmaster, paintpro, promptmaster, apiconnector и agentstudio.

Скиллы являются текстовыми инструкциями для ИИ, а не исполняемыми плагинами. Доступные возможности зависят от инструментов конкретного агента.
